
API REST Segura para Gestión de Productos y Usuarios

# Requerimientos mínimos
Para este proyecto, se utilizó Java 21 y SpringBoot. 
Las dependencias instaladas en 'pom.xml' son:
- jpa
- validation
- h2 database
- assertj
- mockito
- hamcrest
- spring security
- nimbusds
- spring security test
